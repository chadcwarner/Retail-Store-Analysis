# Retail-Store-Analysis
Retail Store Sales Analysis Project

Welcome to the Retail Store Sales Analysis repository! This project is designed to simulate a real-world retail business database for practicing SQL analysis, database management, and business intelligence reporting.

## Project Overview

This project builds a relational database named Retail Database that captures:

#### - Customer information
#### - Product catalog
#### - Orders placed
#### - Items sold within each order

#### *** The dataset includes 1000 Customers, 1000 Products, 1000 Orders, and 1000 OrderItems.

### Relationships:

One Customer can have many Orders
One Order can have many OrderItems
One Product can appear in many OrderItems

## It is ideal for:

### SQL practice (basic to advanced queries), Business analysis and reporting, and Portfolio and interview preparation
